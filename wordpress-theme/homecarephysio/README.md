# HomeCare Physio WordPress theme

This theme is designed for the **HomeCarePhysio** site in LocalWP. It contains the shared layout and styling; `seed-pages.php` creates or updates the 16 editable WordPress pages, sets the Home page as the front page, and builds the primary and footer menus.

From the LocalWP Site Shell, run:

```sh
wp theme activate homecarephysio
wp eval-file wp-content/themes/homecarephysio/seed-pages.php
```

Service scope, locations, prices, clinician profiles, testimonials, contact details, and legal wording remain marked for confirmation in the page content.
